# Clovercut 0.1.5

This desktop release expands the creative libraries and brings media-decoding,
caption-timing and export reliability improvements adapted from Concat.

## Creative libraries

- Star filters, effects, transitions and GIPHY stickers, and browse Favourites, Most used and Recent views. The stars use centred vector icons.
- Browse and download 123 supported GL transitions on demand. Hover over a transition card for an animated preview.
- Fix YouTube Audio Library and Freesound browsing/downloads and reorganise Content Library settings.
- Libraries open on All. Enter still submits audio/sticker searches, then releases keyboard focus; Escape releases it too.
- Filter auditions have a visible preview label and close button. Text and captions expose their generic effects chain alongside Clovercut's existing style and animation controls.

## Editing, playback and imports

- Reduce accidental track creation when moving clips within their current track.
- Prioritise media-card pictures over background waveform and filmstrip work, using suitable keyframes with an exact fallback.
- Keep separate rolling readers for a transition between distant cuts of the same file, while reusing readers for neighbouring playback requests.
- Improve MPEG-TS/camera-file seeking, coarse timestamps, variable-frame-rate pauses, non-square pixel display and recovery from damaged packets.
- Preserve offsets between a file's picture and sound in preview, transcription and export. A regression reproduced this distinct case before the fix; Clovercut's existing playback-clock polish and pitch-preserving speed curves remain.

## Captions and export

- Backport Whisper's consecutive-timestamp fix and bundle the small MIT Silero voice detector to tighten captions to detected speech. Caption groups, timeline-wide transcription and animations remain available.
- Keep transition chains below logos and higher tracks, independent of clip-list order.
- End the video and audio mix on the timeline's frame grid.
- Restart once in software if the hardware encoder stops taking frames, reporting the change and resetting progress/ETA. Cancellation, GPU recovery and final output replacement remain.

## Desktop packages

- Linux x86_64 and ARM64: AppImage.
- Windows x64 and native ARM64: installer and portable ZIP.
- macOS Intel and Apple Silicon: DMG.
- Android and iOS packages are excluded from this release. The previous Android release remains available separately.

All eight desktop packages are included and their platform startup smoke tests passed before publication. The release also includes
`manifest.json` and `SHA256SUMS`.

## Packaging corrections

- Include the six legacy GL transition cards and correct Doorway's outward door motion, with start/midpoint/end GPU regression probes.
- Use Homebrew's full FFmpeg build on both macOS architectures, preserving the Rubber Band filter required by pitch-preserving speed changes. Check required filters before compiling.
- Fix Windows x64 linking with dynamically loaded Whisper CPU modules by querying CPU capabilities through the selected backend registry. Keep the regular Windows build profile and validate startup on older CPU instruction sets.
- Update the checksum-pinned Windows ARM64 FFmpeg build: the previous avcodec DLL crashed during loading before the editor could start. The new build passes isolated DLL startup probes on a native Windows ARM runner.
- Include the desktop-first documentation and WAV channel-layout, updater TLS, VAD cache, font-picker keyboard and visual-layer copy improvements described in [Concat adaptations](../UPSTREAM.md).

## Validation

The corrected Doorway shader passes all 381 package GPU probes locally. The six
new bundled cards are rendered by Clovercut's compositor at 480×270. Native
Windows ARM library startup probes pass with the updated pinned FFmpeg.
The release workflow requires the complete CI suite and every desktop package's
startup smoke test to pass before publication. Version 0.1.4 was not published;
this version keeps its failed source tag intact.
