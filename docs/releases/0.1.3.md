# Clovercut 0.1.3

Clovercut 0.1.3 introduces sharp vector SVG branding, 1:1 square media preview cards, updated sunset and city reference stills, expanded transition packages, full-timeline auto-captions, single-track playhead slicing, strict track layout constraints, and compiler stability tuning.

## Highlights & Major Features

### Crisp Vector SVG Branding & Hi-DPI UI Graphics
- **Native Vector Assets:** Integrated `assets/applogo.svg` and `assets/typography.svg` directly into the title bar, start screen, settings dialog, and export modals to eliminate aliasing and jagged edges on all display scaling factors.
- **High-Fidelity Icon Generation:** Regenerated all raster desktop icons (`.png`, `.ico`) with multi-sampling directly from vector sources.

### Squarer Preview Cards & CapCut Shelf Proportions
- **1:1 Square Visual Previews:** Standardized media shelf tiles (`CatalogueCard` and `ShelfGrid`) to use a 1:1 square aspect ratio for Transitions, Effects, Filters, and Adjustments, matching the clean modern CapCut desktop design.

### Sunset & City Reference Preview Stills
- **Theme-Aware Preview Cards:** Replaced the legacy portrait still with two high-definition reference scenes:
  - **Sunset Still (`STILL_SUNSET`):** Applied to warm/calm color filters, adjustments, and atmospheric effects.
  - **City Still (`STILL_CITY`):** Applied to high-energy glitch, distortion, and motion effects.
  - **Live Transition Previews:** Transition cards demonstrate the cut dynamically from the sunset scene to the city scene.

### Expanded Built-in Transitions Library
- Added 7 new transition effects with bundled WGSL shaders and GPU card previews:
  - `Barn Door`
  - `Circle Close`
  - `Cover Left`
  - `Cover Right`
  - `Wipe Up`
  - `Wipe Down`
  - `Pixelize Transition`

### Full Timeline Auto-Captions
- **Continuous Project Transcription:** Auto-captions transcribe across the entire project audio timeline regardless of individual clip cuts and edits on the timeline, ensuring synchronized full-video subtitle generation in a single pass.

### Single Active Track Playhead Cutting
- **Playhead Razor Precision:** Slicing at the playhead (`Ctrl+B` / Split) now targets only the active/selected track rather than cutting across every track on the timeline.

### Strict Visual Track Constraints
- **Adjustment Layer Boundary:** Visual effects and adjustment layers are strictly restricted to the visual zone (on or above the main video track) and cannot create tracks below the primary video lane.

### Complete English Localization Consistency
- Normalized timeline labels, context menus, and badges into standard English (`+ New Track`, `Group with Captions`, `Ungroup Captions`, etc.).

### Build & Memory Stability
- Configured bounded code generation units (`codegen-units = 2` on Slint code gen) for stable builds on systems with 16GB RAM.
