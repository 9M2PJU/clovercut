# Clovercut 0.1.8

Desktop release for Linux x86_64/aarch64, Windows x86_64/ARM64 and macOS Intel/Apple Silicon. Mobile packages are not included.

## More predictable editing

- Default the main video track to the existing Medium height (80 px) and give other video and audio tracks the former main-video height (64 px). Preserve other automatic heights and explicit manual sizes.

- Keep the element selected in the timeline as the drag target in the preview, reducing accidental selection of overlapping elements.
- Extend generated clips such as stickers to the left as well as to the right, while retaining source limits for recorded media.
- Add optional timeline linkage, anchored to Clovercut's fixed main video track. Linked ripple edits move following material together while respecting locked tracks, crossing audio beds and typed-track placement. Linkage is off by default, including in existing projects.
- Resolve linked multi-track deletions and trim/speed batches once, with undo/redo and consistent trim previews.

## Text and creative libraries

- Style selected words or characters independently: colour, weight, italic, underline, strikethrough and relative size. Keep whole-title styling, Unicode edits, vertical text and caption-group behaviour.
- Preserve word styles through copying, presets, saving, undo and export. Per-word changes to a caption affect that caption rather than every caption in its collection.
- Open the Text library on Styles, with the saved default-title card above the presets. Keep click/drag insertion and the separate Languages category; remove the redundant Titles category.
- Make YouTube Studio preview controls independent of the account's interface language.

## Global audio effects

- Drag an audio effect onto the timeline to create a sound-effect layer over the summed soundtrack. Clicking an effect keeps applying it to the selected clip.
- Control layer strength, fades and keyframes; overlapping layers follow their track order. Muting an effect layer bypasses that layer without muting the underlying audio.
- Share continuous source retiming, volume curves and effect history between preview and export. Keep original audio audible until a background mix is ready.
- Cancel obsolete preview jobs and safely publish mixed-audio caches across edits and project changes.

## Canvas and transparent exports

- Set a colour and alpha for each timeline's canvas, with checkerboard previews of transparent areas.
- Export transparency with ProRes 4444 in MOV with AAC audio, or VP9 alpha in WebM with Opus audio. Ordinary MP4 output flattens transparency onto black.
- Correct premultiplied-alpha handling across filters, transitions, prepared pictures and CPU/GPU preview paths.

## Documentation and compatibility

- Refresh the README and website with seven real 1080p captures from the current desktop build, with matching full-size gallery views and detail crops.
- Translate the new controls across all 25 supported languages.
- Keep existing projects, compact typed tracks, caption collections, generated-media ownership, continuous speed ramps, cancellable exports and atomic output publication.
