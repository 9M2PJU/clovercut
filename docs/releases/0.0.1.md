# Clovercut 0.0.1

The first Clovercut release: an independent, local video editor for Linux, based on Concat.

- Clovercut branding, application icon and Linux desktop identity.
- Aligned inspector sliders with editable values, units and up/down buttons.
- Paired X/Y position keyframes and separate Color, Curves and Wheels tabs.
- Improved title shadow performance and text bounding boxes.

## Download and run

Download `Clovercut-0.0.1-x86_64.AppImage` for Intel/AMD Linux PCs, or
`Clovercut-0.0.1-aarch64.AppImage` for ARM64 Linux. Make it executable and open it:

```sh
chmod +x Clovercut-0.0.1-x86_64.AppImage
./Clovercut-0.0.1-x86_64.AppImage
```

On systems without FUSE, run with `APPIMAGE_EXTRACT_AND_RUN=1`.
The build targets Ubuntu 22.04 / glibc 2.35 or newer. System graphics drivers,
GTK 3, ALSA and font libraries are still required. Optional AI models download separately.

This is an early release. Save and back up editing projects regularly.
Clovercut uses its own settings and cache directories, under
`io.github.tulcoturo.clovercut`; existing Concat project folders can still be opened.

`SHA256SUMS` contains the checksums; `manifest.json` supports the in-app version checker.

Clovercut is based on the work of Jareer and the Concat contributors and remains
AGPL-3.0-or-later. It is not an official Concat distribution.
