# Clovercut 0.0.2

This release adds Windows x64 packages and improves library playback, effects,
transitions, captions and inspector controls.

## Changes

- Videos imported into a new project can be previewed and played directly from
  the library, even with an empty timeline or the playhead in a gap.
- Library previews ignore timeline track visibility and mute switches.
- Extended Giphy GIF stickers repeat in preview and export.
- Linux modifier reconciliation prevents stuck multi-selection after missed key releases.
- Online audio and sticker libraries, direct dragging of effects onto clips,
  LUT controls and entry/exit animations.
- Editable transition parameters, bundled effect thumbnails and correct filter
  layers over transitions.
- Inspector improvements for narrow panes and touch screens, plus caption styling refinements.
- The current project is saved and released before another project opens.
- Windows Direct3D shader compilation uses FXC by default to avoid loading an
  incompatible shader compiler from another application.

## Packages

- Linux Intel/AMD: `Clovercut-0.0.2-x86_64.AppImage`
- Linux ARM64: `Clovercut-0.0.2-aarch64.AppImage`
- Windows x64 installer: `Clovercut-0.0.2-windows-x86_64-setup.exe`
- Windows x64 portable: `Clovercut-0.0.2-windows-x86_64-portable.zip`

On Linux, make the AppImage executable before opening it. Ubuntu 22.04 /
glibc 2.35 or newer is required; `APPIMAGE_EXTRACT_AND_RUN=1` works without FUSE.
On Windows, run the installer or extract the whole portable ZIP and open
`clovercut.exe`. The Windows packages are unsigned; publisher verification is
not provided. Native Windows ARM64 packages are not included in this release.

AI models download separately. `SHA256SUMS` verifies all four packages and
`manifest.json` provides package sizes, hashes and in-app update links.

Clovercut is an early release. Back up important editing projects.
Settings and caches are separate from Concat, under the Clovercut application
identity. Existing Concat project folders remain compatible.
