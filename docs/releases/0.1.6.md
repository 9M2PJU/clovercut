# Clovercut 0.1.6

## Copy, paste and duplicate

- Preserve complete clip settings, including masks, cutout, stabilization, Enhance references, backgrounds, audio streams, speed curves, effects and animation keys.
- Copy in one project, open another in the same window and paste with the correct media references and compatible unlocked tracks. Files owned by the source project are copied into the destination before placement. External media remain references and use the existing relink flow when missing.
- Keep pasted caption groups independent from existing captions. Duplicate a selection as one group and one undo step, preserving timing, caption membership and detached-audio links.
- Prepare resources on a worker with cancellation, temporary staging and resource reuse. Failed or stale deliveries remove their own staged files. Conflicting custom font files cannot silently replace destination fonts.

## Desktop editing layout

- Use the timeline toolbar’s plus button to add a timeline. Show timeline tabs only when the project has more than one timeline, keeping the pane switcher accessible in either layout.
- Use a compact 52 px automatic track height while preserving the existing manual sizes.
- Page through complete groups of library categories with the arrow buttons while preserving wheel scrolling and the selected category. Remove the extra underline from the library header.
- Enlarge library category icons, increase spacing and highlight boxed sidebar categories with the theme accent. Keep categories accessible by scrolling in short panels.
- Draw transition indicators and duration handles above both adjacent clips, independently of clip insertion order.

## Inspector

- Use Clovercut green (`#24d47a`) as the default accent while preserving saved color choices.

- Adapt parameter rows to the available desktop width while preserving numeric editing, units, sliders, keyframes and touch targets.
- Use quieter tab navigation with complete option names available on hover.
- Give LUT selection more space and expose `.cube` import as a secondary action, preserving multiple LUTs and independent intensity controls.
- Fold color parameter groups independently and reset a group through the existing editing transaction and animation semantics.
- Derive minimum inspector widths from the active page, independently for each inspector, while retaining adjustable panel widths and the other panes' existing minimum.

## Translations

- Translate pending captions, online libraries, favourites, shortcuts, layout controls, clip merging, paste messages and animation hints across all 24 non-English languages.
- Translate saved/unsaved project status and caption grouping context-menu actions that previously bypassed the language system.
- Localize audio card category labels that previously bypassed translation. Remove the old index’s unverified blanket royalty-free label from YouTube cards.
- Validate nonempty strings and numbered placeholders, and reject new untranslated English in CI. Exact reviewed cognates, product names and units remain valid.

## YouTube Audio Library

- Integrate the Clovercut YouTube Audio API with separate music and sound effects, paginated search, offline catalogue caching, per-track licence details and credit copying. Add a configurable API address in Content libraries and translate its controls and connection messages across all supported languages.
