# Clovercut 0.1.1

Clovercut 0.1.1 is a major milestone release establishing Clovercut as an independent, local-first CapCut-style video editor. This release brings complete visual identity polish, upstream engine and media optimizations, Whisper auto-captions, 3D LUT grading, and official releases across Linux (AppImage), Windows (installer and portable), and Android (APK).

## Latest Editing Fixes

- Typed timeline tracks for video, audio, text, captions, stickers, and filters.
- Improved track insertion, drag previews, and empty-track cleanup.
- Playhead editing and live inspector fixes.
- Restored transition source-handle safety.
- Full engine checks run for releases and manual requests, rather than every push.

## Highlights & Major Features

### CapCut-Inspired Visual Polish & Layout Symmetry
- **Refined TitleBar & Application Header:** Perfectly vertically centered branding featuring the emerald clover mark and balanced typography hierarchy.
- **Export Modal Symmetry:** Redesigned export header aligning icon scale, title baseline, and layout padding seamlessly with the main interface.
- **Unified Squircle Branding:** New modern clover iconography applied across all resolutions (`16px`, `32px`, `64px`, `128px`, `256px`, `512px`).
- **High-Resolution 16:9 Showcase:** Visual evidence and walkthrough suites refreshed to crisp widescreen dimensions (`2508 x 1416`).
- **Responsive Layout Stability:** Full layout adaptability across ultra-wide, 1440p, 1080p, and narrow compact workflows.

### Upstream Concat Integrations & Engine Performance
- **WebM Alpha Transparency:** Native decoding for VP8/VP9 alpha layers directly composited in the GPU rendering pipeline.
- **GPU Seek Optimization:** Low-latency random frame access eliminating decoder stalls during scrubbing and timeline skimming.
- **SVG Vector Stills:** Direct vector graphics import rasterized crisply to any project canvas resolution.
- **VLC MP4 Seek Tolerance:** Resilient keyframe handling for non-standard MP4 index tables.
- **Multi-Monitor Windows Fix:** Accurate device name identification across complex display configurations.
- **Graceful macOS Session Handling:** Immediate project auto-save on `Cmd+Q` or window termination.
- **Timeline Diamond Keyframes:** Visual diamond markers for clear, intuitive keyframe curve tracking.

### Audio & Subtitle Studio
- **Local Whisper Auto-Captions:** Integrated speech-to-text generating word-level subtitle tracks directly on your device without cloud subscription dependencies.
- **Dedicated Subtitle Inspector:** Granular control over caption styling, fonts, outlines, backgrounds, and placement.
- **Continuous Pitch-Preserving Speed Curves:** Audio speed ramps without pitch shifts or clicks.
- **Live VU Meters:** Stereo and multi-channel audio monitoring during playback and scrubbing.

### Color Grading & Visual Effects
- **3D LUT Grading:** Real-time `.cube` LUT application on video and image clips.
- **Color Wheels:** Interactive Lift, Gamma, and Gain wheels with fine-tuned shadow/highlight adjustments.
- **Royalty-Free Asset Libraries:** Integrated browsing for GIPHY animated stickers, OpenGameArt sound effects, and vector graphic libraries.
- **Drag-and-Drop Transitions:** Smooth scene transitions with customizable durations and parameters.

## Platform Packages

- **Linux x86_64:** `Clovercut-0.1.1-x86_64.AppImage`
- **Linux ARM64:** `Clovercut-0.1.1-aarch64.AppImage`
- **Windows x64 Setup:** `Clovercut-0.1.1-windows-x86_64-setup.exe`
- **Windows x64 Portable:** `Clovercut-0.1.1-windows-x86_64-portable.zip`
- **Android ARM64:** `Clovercut-0.1.1-android-arm64.apk`

### Installation & Verification

- **Linux:** Make the AppImage executable (`chmod +x Clovercut-0.1.1-x86_64.AppImage`) and run. Compatible with Ubuntu 22.04+ / glibc 2.35+ or via FUSE / `APPIMAGE_EXTRACT_AND_RUN=1`.
- **Windows:** Run the setup installer or extract the portable ZIP and run `clovercut.exe`.
- **Android:** Sideload the APK onto any ARM64 device running Android 8.0 (API 26) or higher.
- **Integrity:** Verify package authenticity using the published `SHA256SUMS` and `manifest.json`.
